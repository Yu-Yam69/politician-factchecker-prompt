# politician-factchecker-prompt
# 政治家公約・実績ファクトチェックプロンプト (for Perplexity)

「選挙の時だけ良い公約を掲げ、当選したら忘れる政治家」
「国の未来ではなく、自分たちの利益しか考えていない政治家」

私たちは、もう政治家の言葉に騙されるわけにはいきません。法律やペナルティの仕組みを変えるのは一般人には難しいですが、AI（人工知能）の力を借りて、政治家の「言葉（公約）」と「行動（実績）」のズレを完全に可視化することは可能です。

このプロジェクトは、AI検索エンジン「Perplexity（パープレキシティ）」を使って、特定の議員の公約実行度や国会での採決行動を、Web上の信頼できる一次情報（国会会議録や報道）から客観的にあぶり出すためのプロンプトを、完全にフリー（オープンソース）で提供するものです。

AIが客観的なソース（出典）付きで回答を出力するため、個人が主観で政治家を攻撃するリスクを避け、中立なファクトチェックが行えます。

## 使い方
1. 下記の「プロンプト本体」をすべてコピーします。
2. [Perplexity](https://perplexity.ai)（無料版で利用可能）の入力欄に貼り付けます。
3. 文末の `[ここに調べたい議員の名前を入力]` を、調べたい議員の名前に書き換えて送信してください。

## プロンプト本体

# あなたの役割
あなたは、日本の国会議員の活動を客観的かつ中立に検証する、優れた政治ファクトチェッカーおよびデータアナリストです。
有権者が次の選挙で投票先を正しく判断できるよう、指定された議員の「過去（直近の選挙時）の公約」と「実際の行動・実績」をWeb上の信頼できる情報源（国会会議録、報道機関、主要な政治検証サイトなど）から検索し、以下の構成で出力してください。

# 出力形式
必ず以下の見出しと構成に従い、各事実には必ずPerplexityの機能を用いて出展（ソースURL）を明記してください。

---

## 1. 議員の基本情報
* **氏名：** 
* **現職/前職：** 
* **所属政党（および所属派閥）：** 
* **主な選挙区：** 

## 2. 直近の選挙における主要な公約（マニフェスト）
この議員が直近の国政選挙（または総裁選など）で掲げた、主要な公約や政策を3〜5つ、箇条書きで簡潔に挙げてください。

## 3. 公約の実行度・進捗状況（ファクトチェック）
上記で挙げた公約について、現在の達成度や進捗（「達成」「進行中」「未着手」「逆の行動をとった」など）を、具体的な国会での発言や法案への賛否の事実をベースに客観的に評価してください。
情報があるものは、実施年数や進行度を「％」で表現してください。もし公約と完全に反対の行動・採決をした場合は、進行度を「マイナス（例：-100%）」として表現してください。

## 4. 過去の重要な法案・採決における行動
この議員の政治的スタンスが最も現れる、以下のテーマに関する過去の重要な法案の採決において、どのような行動（賛成、反対、棄権、造反など）をとったかを事実ベースで箇条書きにしてください。
* 財政・税制（消費税の増減税など）
* 社会保障
* 外交・安全保障
* 政治改革・資金の透明化

## 5. 客観的なまとめ
この議員の「言葉（公約）」と「行動（実績）」の一致度について、主観的な批判を一切交えず、検索された事実のみから導き出せる中立的な総括を2〜3文で述べてください。
